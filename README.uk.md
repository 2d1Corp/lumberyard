# Lumberyard

[English](README.md) | **Українська**

Lumberyard — мій перший навчальний проєкт на Django. Це невеликий
вебзастосунок для підприємства, що працює з деревиною. Він складається з двох
частин:

- публічного сайту з каталогом матеріалів у режимі лише для читання;
- внутрішнього робочого простору для керування складською інформацією.

Проєкт створено під час мого навчання Python і Django.

## Жива демо-версія

Розгорнуто на Render: https://lumberyard.onrender.com

## Можливості

### Публічні сторінки

- Головна сторінка
- Каталог матеріалів
- Пошук за назвою матеріалу або SKU
- Фільтрація за категорією
- Детальна інформація про матеріал і статус його наявності
- Інформація про доставку та контакти

Публічний каталог показує лише загальний статус наявності `Available` або
`Contact us`. Він не показує точну кількість матеріалу, назви внутрішніх
складів, постачальників, їхні SKU або закупівельні ціни.

### Внутрішній робочий простір

Авторизовані працівники можуть:

- переглядати панель керування з актуальними даними проєкту;
- створювати, редагувати, шукати й видаляти матеріали;
- керувати категоріями, складами та постачальниками;
- оновлювати кількість матеріалів на кожному складі;
- керувати пропозиціями постачальників і закупівельними цінами;
- створювати й скасовувати ручні запити на поповнення;
- переглядати облікові записи працівників;
- створювати й видаляти облікові записи за наявності відповідних дозволів;
- поточний обліковий запис і superuser захищені від видалення через внутрішній
  інтерфейс.

## Модель даних

Проєкт використовує сім основних моделей:

- `Worker` — власна модель користувача Django для працівників;
- `Category` — група матеріалів;
- `Material` — інформація про товар у каталозі;
- `Warehouse` — місце зберігання;
- `StockBalance` — кількість матеріалу на конкретному складі;
- `Supplier` — інформація про постачальника;
- `MaterialSupplier` — пропозиція постачальника для конкретного матеріалу.

## Локальний запуск

Потрібен Python 3.12 або новішої версії.

1. Клонуйте репозиторій і відкрийте директорію проєкту:

   ```bash
   git clone https://github.com/2d1Corp/lumberyard.git
   cd lumberyard
   ```

2. Створіть віртуальне середовище:

   ```bash
   python -m venv venv
   ```

3. Активуйте його.

   У Windows PowerShell:

   ```powershell
   .\venv\Scripts\Activate.ps1
   ```

   У macOS або Linux:

   ```bash
   source venv/bin/activate
   ```

4. Встановіть залежності:

   ```bash
   python -m pip install -r requirements.txt
   ```

5. Створіть локальний файл оточення.

   У Windows PowerShell:

   ```powershell
   Copy-Item .env.example .env
   ```

   У macOS або Linux:

   ```bash
   cp .env.example .env
   ```

   Значення з прикладу підходять для локальної розробки. Поза локальним
   середовищем використовуйте окремий секретний ключ, встановіть
   `DJANGO_DEBUG=False` і налаштуйте `DJANGO_ALLOWED_HOSTS` для адреси
   розгорнутого застосунку.

6. Застосуйте міграції бази даних:

   ```bash
   python manage.py migrate
   ```

7. Завантажте демонстраційні дані каталогу та складу:

   ```bash
   python manage.py seed_data
   ```

8. Створіть користувача для внутрішнього робочого простору:

   ```bash
   python manage.py createsuperuser
   ```

9. Запустіть сервер для розробки:

   ```bash
   python manage.py runserver
   ```

Відкрийте `http://127.0.0.1:8000/` у браузері. Внутрішній робочий простір
доступний після входу за адресою `http://127.0.0.1:8000/login/`.

## Демонстраційні дані

Команду `seed_data` можна безпечно запускати декілька разів. Вона створює
невеликий набір демонстраційних даних:

- 2 категорії матеріалів;
- 8 матеріалів із деревини та листових матеріалів;
- 2 склади;
- 2 постачальники;
- складські залишки та пропозиції постачальників.

Команда не створює обліковий запис працівника.

## Основні сценарії

### Відвідувач

1. Відкрити головну сторінку.
2. Переглянути каталог або скористатися пошуком.
3. Відкрити сторінку матеріалу.
4. Перевірити загальний статус наявності та скористатися інформацією про
   доставку або контактами.

### Працівник

1. Увійти й відкрити панель керування.
2. Знайти або створити матеріал.
3. Оновити його складські залишки та пропозиції постачальників.
4. За потреби створити запит на поповнення для конкретного складу.

## Межі проєкту

Це навчальний проєкт, а не готова виробнича система складського обліку. Він
демонструє основні моделі, форми, views, автентифікацію, дозволи, шаблони й
тести Django.

Lumberyard не є інтернет-магазином, бухгалтерською системою, CRM або
повноцінною системою керування складом. У ньому немає облікових записів
клієнтів, замовлень, платежів чи автоматичних закупівель.
